# 모아보드

메모를 자유롭게 배치하고, 내용을 가렸다가 확인하면서 공부하는 개인용 화이트보드입니다.

## 바로 실행하기

**index.html**을 브라우저에서 열면 사용할 수 있습니다. GitHub Pages에 배포하면 사이트 주소로 접속해서 사용할 수 있습니다.

회원가입, 로그인, 데이터베이스, API 키, 별도의 설치나 빌드 과정이 필요하지 않습니다. 아이콘도 파일 안에 포함되어 있습니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다. 저장소 이름 예시: **moa-board**.
2. GitHub Free에서 배포할 경우 저장소를 **Public**으로 만듭니다.
3. 압축을 풀고, 아래 파일을 저장소의 최상위에 업로드합니다.

| 파일 | 역할 |
| --- | --- |
| index.html | 실행에 필요한 화면·스타일·기능이 모두 들어 있는 홈페이지 |
| .nojekyll | 정적 파일을 그대로 배포하기 위한 설정 |
| README.md | 사용 방법 |
| THIRD-PARTY-NOTICES.txt | 포함된 아이콘의 라이선스 |

4. **Add file → Upload files**에서 파일을 올리고 **Commit changes**를 누릅니다.
5. 저장소에서 **Settings → Pages**를 엽니다.
6. **Build and deployment**에서 다음과 같이 설정합니다.

| 설정 | 선택 |
| --- | --- |
| Source | Deploy from a branch |
| Branch | main |
| Folder | /(root) |

7. **Save**를 누릅니다.
8. 배포가 끝나면 Pages 화면의 **Visit site**로 접속합니다.

일반 저장소의 주소 형식은 https://사용자이름.github.io/저장소이름/ 입니다. 예를 들어 사용자 이름이 Taetaeeee, 저장소 이름이 moa-board라면 https://taetaeeee.github.io/moa-board/ 가 됩니다.

압축파일 자체가 아니라, 압축을 푼 파일을 올립니다. **index.html은 main 브랜치의 최상위에 있어야 합니다.**

공식 안내:

- https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
- https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

## 기본 사용

평소에는 편집·암기 모드 전환과 메모만 표시됩니다. 페이지와 파일 메뉴는 **P** 키로 열 수 있습니다.

| 동작 | 기능 |
| --- | --- |
| 편집 모드에서 빈 공간 우클릭 | 해당 위치에 새 메모 생성 |
| 메모 더블클릭 | 메모 안에서 제목과 본문 수정 |
| 메모 드래그 | 개별 메모 이동 |
| Shift + 메모 클릭 | 여러 메모 선택 |
| 편집 모드에서 메모 우클릭 | 색상·분류·소속 페이지·가릴 범위·그룹 등 설정 |
| 같은 그룹 선택 후 드래그 | 그룹 메모 함께 이동 |
| 빈 공간 드래그 / Space + 드래그 | 보드 화면 이동 |
| Ctrl + 휠 | 확대·축소 |
| 암기 모드에서 메모 우클릭 | 해당 메모의 블러 켜기·끄기 |

그룹에 포함되어 있어도 메모는 기본적으로 하나씩 이동합니다.

모바일에서는 메모가 읽기 편한 세로 목록으로 표시됩니다. 자유로운 공간 배치와 마우스 우클릭은 PC 브라우저 사용을 권장합니다.

## 단축키

| 키 | 기능 |
| --- | --- |
| M | 편집·암기 모드 전환 |
| P | 페이지별 보기·전체 모아보기·파일 메뉴 |
| N | 새 메모 |
| F | 현재 보기의 전체 메모 맞춤 |
| B | 암기 모드에서 선택한 메모의 블러 전환 |
| Enter | 선택한 메모 수정 |
| Ctrl + Enter | 수정 완료 |
| Esc | 수정 취소 / 메뉴 닫기 |
| Ctrl + S | 보드 전체를 JSON 파일로 저장 |
| Ctrl + O | 저장한 JSON 파일 불러오기 |
| Ctrl + Z | 실행 취소 |
| Ctrl + A | 현재 보기의 메모 전체 선택 |
| Ctrl + G | 같은 페이지의 선택 메모를 그룹화 |
| Ctrl + Shift + G | 그룹 해제 |
| Ctrl + D | 선택한 메모 복제 |
| Delete | 선택한 메모 삭제 |

macOS에서는 Ctrl 대신 Command를 사용할 수 있습니다. 메모에 글을 입력하는 동안 일반 문자 단축키는 실행되지 않습니다.

## 로그인 없는 저장·복원

**P → 파일로 저장** 또는 **Ctrl + S**를 누르면 **moa-board-날짜.json** 파일이 다운로드됩니다.

파일에는 모든 페이지, 메모의 내용·분류·색상·그룹·위치, 페이지별 화면 상태, 전체 보기의 배치, 블러 상태가 포함됩니다.

**P → 파일 불러오기** 또는 **Ctrl + O**에서 이전 JSON 파일을 선택하면 바로 복원됩니다. 다른 PC에서도 같은 홈페이지에 접속한 뒤 파일을 열 수 있습니다.

- 공부 내용은 브라우저 안에서 처리되며 서버에 업로드되지 않습니다.
- 새로고침하거나 창을 닫기 전에 JSON 파일로 저장해 주세요.
- 불러오기는 현재 보드를 파일의 내용으로 교체합니다. 직후 **Ctrl + Z**로 불러오기 전 보드로 돌아갈 수 있습니다.
- 올바르지 않은 파일은 현재 보드를 변경하지 않습니다.
- 저장 파일은 최대 10MB, 200개 페이지, 5,000개 메모까지 불러올 수 있습니다.
- 화면을 인쇄하거나 이미지로 저장하는 형식과 달리 JSON 파일은 나중에 다시 편집할 수 있습니다.

## 업데이트

홈페이지를 수정하려면 GitHub에서 **index.html**을 새 버전으로 교체하고 커밋합니다. 같은 배포 설정으로 변경 사항이 반영됩니다.
