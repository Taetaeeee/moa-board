# 모아보드 (Moa Board)

메모를 자유롭게 배치하고, 내용을 가렸다가 확인하며 공부하는 개인용 웹 화이트보드입니다.

**[모아보드 바로 사용하기](https://taetaeeee.github.io/moa-board/)** · **[GitHub 저장소](https://github.com/Taetaeeee/moa-board)**

회원가입·설치·서버 데이터베이스 없이 브라우저에서 실행합니다. 상단에 편집 모드·암기 모드·**메뉴 P** 버튼이 표시됩니다. 메뉴 버튼 또는 **P** 키로 페이지·파일·꾸미기 메뉴를 엽니다.

## 이번 버전의 기능

| 기능 | 사용 방법 |
| --- | --- |
| 자유 배치 | 빈 곳 우클릭으로 메모 추가, 드래그로 개별 이동 |
| 드래그 다중 선택 | 편집 모드에서 빈 곳을 드래그하면 사각형에 걸친 메모들을 선택. Shift + 드래그로 선택 추가 |
| 메모 복사·붙여넣기 | 편집 모드에서 메모 선택 후 Ctrl + C / Ctrl + V. 여러 메모·페이지 간 붙여넣기 지원 |
| 메모 간 관계 | 메모 우클릭 → 이 메모에서 화살표 연결 → 도착 메모 클릭. 이동·크기 변경에 맞춰 연결 유지 |
| 넓은 확대·축소 | Ctrl + 휠로 0.1%~500% 조절. F 키는 멀리 떨어진 메모까지 전체 맞춤 |
| 현재 페이지 정렬 | P → 현재 페이지 정렬. 다른 페이지는 유지하고 현재 페이지의 메모를 격자로 정리 |
| 자동 저장 | 같은 사이트·브라우저 프로필에서 새로고침·재접속 시 복원. 작성 중인 내용도 보관 |
| 배경지 | P → 화면 꾸미기에서 도트·모눈·줄 노트·무지·배경색 및 사용자 이미지 선택 |
| 테마 | 베이직·화이트·라이트·다크 또는 브라우저 설정 따르기 |
| 메모 색상 | 위쪽 자유 색상, 아래쪽 기본 18색 팔레트. HEX 입력·최근 색상·여러 메모에 한 번에 적용 |
| 사용자 분류 | 메모 우클릭 → 분류 직접 입력. 비우면 미분류 |
| 텍스트 강조 | 메모 더블클릭 → 글자 선택 → 굵게·밑줄·형광펜 버튼 |
| 글머리 기호 | 편집 도구의 • 목록 버튼으로 본문 전체를 목록·일반 문장으로 전환 |
| 크기 조절 | 편집 모드에서 메모의 네 모서리 드래그 |
| 암기 | 암기 모드에서 메모 우클릭으로 블러 켜기·끄기 |
| 파일 백업 | Ctrl + S로 모든 페이지를 JSON 다운로드, Ctrl + O로 불러오기 |

## 시작하기

1. [사이트](https://taetaeeee.github.io/moa-board/)를 열고 사용법 안내에서 **시작하기**를 누릅니다.
2. 처음 사용하는 브라우저에서는 예시 메모 없는 빈 보드가 나옵니다. 자동 저장본이 있다면 복원합니다.
3. 편집 모드에서 빈 곳을 우클릭하고 제목·본문을 입력합니다.
4. **완료** 또는 **Ctrl + Enter**로 편집을 마칩니다. 이후 더블클릭으로 다시 편집합니다.
5. 암기 모드에서 메모를 우클릭해 내용을 가리고 확인합니다.

안내의 **다음부터 보지 않기**는 해당 브라우저에 기억됩니다. **?** 또는 **P → 사용법 다시 보기**로 안내를 다시 열 수 있습니다.

## P 메뉴와 보드 조작

상단 **메뉴 P** 버튼은 항상 표시되므로 단축키를 기억하지 않아도 메뉴를 열 수 있습니다. 버튼을 다시 누르면 닫힙니다. P 메뉴에는 페이지 추가·전환, 전체 모아보기, 전체 맞춤, 현재 페이지 정렬, 100% 보기, 자동 저장 상태, 테마·배경 설정, 파일 백업·불러오기가 있습니다.

**전체 맞춤(F)**은 화면의 배율과 위치만 바꾸며 메모는 옮기지 않습니다. **현재 페이지 정렬**은 해당 페이지의 메모 위치를 실제로 바꿉니다. 다른 페이지와 그룹 정보는 유지되며 **Ctrl + Z**로 원래 배치를 복원할 수 있습니다. 정렬은 개별 페이지의 편집 모드에서 사용하고 전체 모아보기·암기 모드에서는 비활성화됩니다.

전체 화면이 보드이므로 아래쪽에 별도의 문서 여백이 생기지 않습니다. **편집 모드의 빈 곳 드래그는 사각형 다중 선택**입니다. Space + 드래그, 마우스 가운데 버튼 또는 휠로 화면을 이동합니다. 암기 모드와 터치 화면에서는 빈 곳 드래그로 보드를 이동할 수 있습니다. Ctrl + 휠은 마우스 위치를 기준으로 확대·축소합니다. 긴 메모 안에서는 본문을 스크롤합니다.

메모를 선택하거나 마우스를 올리면 모서리의 크기 조절 손잡이가 나타납니다. 너비는 160~1,600px, 높이는 120~2,000px까지 조절합니다. 암기 모드에서는 이동·크기 조절을 잠급니다. 모바일에서도 보드 배치를 유지하지만, 우클릭 중심의 조작은 PC 브라우저를 권장합니다.

편집 모드에서 빈 곳을 드래그하면 선택 사각형이 나타나며, 사각형에 일부라도 걸친 메모가 선택됩니다. 반대 방향으로 드래그해도 동작하고, **Shift + 드래그**는 기존 선택에 추가합니다. 선택한 메모 하나를 드래그하면 선택한 메모들이 함께 이동합니다. 여러 메모 복사·색상 변경·그룹화에도 같은 선택을 사용할 수 있습니다.

Shift + 클릭으로도 여러 메모를 선택할 수 있습니다. 그룹에 속한 메모도 기본적으로 개별 이동하며, 그룹 전체를 움직이려면 메모 우클릭 → **같은 그룹 선택** 후 드래그합니다. 메모 우클릭 메뉴에서 색상·분류·소속 페이지·가릴 범위·그룹·복제·삭제도 설정할 수 있습니다.

## 텍스트 강조

제목이나 본문의 글자를 드래그해 선택한 뒤 **B / U / 형광펜** 버튼을 누릅니다. 같은 강조 영역 안에서 다시 누르면 해당 강조가 해제됩니다. Ctrl + B와 Ctrl + U도 지원합니다. 붙여넣기는 외부 서식을 가져오지 않고 일반 텍스트로 입력합니다.

**• 목록** 버튼은 본문의 각 줄을 글머리 기호 목록으로 전환합니다. 다시 누르면 일반 문장으로 돌아갑니다. 기존 굵게·밑줄·형광펜은 유지되며, 목록에서 Enter를 누르면 다음 항목으로 이어집니다. 목록 서식은 자동 저장과 JSON 파일, 메모 복사에 함께 포함됩니다.

## 메모 사이 화살표

1. 편집 모드에서 출발 메모를 우클릭합니다.
2. **→ 이 메모에서 화살표 연결**을 누릅니다.
3. 같은 페이지의 도착 메모를 클릭하면 출발 → 도착 방향의 연결선이 생성됩니다. Esc로 연결 작업을 취소할 수 있습니다.

메모를 이동하거나 크기를 바꾸면 연결선의 끝이 메모 가장자리를 따라옵니다. 화면 이동·확대·축소·페이지 정렬·전체 모아보기에도 연결 관계를 유지합니다.

- 선을 클릭하면 아래에 연결 편집 버튼이 나타납니다. **방향 반전** 또는 **화살표 삭제**를 사용할 수 있습니다.
- 선택한 선은 Delete로도 삭제할 수 있습니다. 화살표 생성·삭제·방향 변경은 Ctrl + Z로 되돌릴 수 있습니다.
- 연결된 메모 둘을 함께 복사·붙여넣거나 복제하면 두 메모 사이의 화살표도 독립적인 새 연결로 복사합니다. 메모 하나만 복사하면 원본의 다른 메모와 연결되지는 않습니다.
- 같은 페이지의 메모끼리 연결합니다. 메모 삭제 또는 다른 페이지로 이동 시 관련 연결을 정리하며, 실행 취소하면 복원됩니다.
- 암기 모드에서는 화살표가 보이지만 연결 편집은 잠깁니다.
- 화살표는 자동 저장과 JSON 파일에 포함됩니다. 기존 저장 파일에 화살표 정보가 없으면 연결 없이 정상적으로 열립니다. 이전 앱 버전은 새 목록·연결 정보를 보존하지 않을 수 있으므로 최신 index.html을 사용하세요.

## 메모 복사·붙여넣기

1. 편집 모드에서 메모를 클릭합니다. 여러 개를 복사하려면 Shift + 클릭으로 선택합니다.
2. **Ctrl + C**로 선택한 메모를 복사합니다.
3. 같은 페이지 또는 다른 페이지에서 **Ctrl + V**로 붙여넣습니다.

내용·텍스트 강조·글머리 기호·색상·크기·분류·가림 설정이 유지되며, 여러 메모의 상대적인 간격과 선택한 메모 사이의 화살표도 유지합니다. 복사본은 새로운 메모이며 원본과 독립적으로 수정됩니다. 복사한 메모들의 그룹은 새 그룹으로 연결되므로 원본 그룹과 섞이지 않습니다.

마우스가 보드 위에 있으면 그 위치에, 보드 밖에 있으면 현재 화면 가운데에 붙여넣습니다. 같은 위치에서 연속으로 붙여넣으면 겹치지 않도록 조금씩 옮겨 배치합니다. 붙여넣은 메모들은 자동 선택되며 **Ctrl + Z 한 번**으로 직전 붙여넣기를 취소할 수 있습니다.

메모의 제목·본문·분류 등 텍스트를 입력하는 동안에는 일반적인 텍스트 복사·붙여넣기로 동작합니다. 메모 전체 복사·붙여넣기는 편집 모드에서 사용합니다. 브라우저가 메모 클립보드 형식을 유지하면 다른 탭의 모아보드에도 붙여넣을 수 있습니다. 장기 보관이나 다른 컴퓨터로의 이동에는 JSON 파일 백업을 사용하세요.

## 색상 팔레트

- 메모 우클릭 → 테두리와 색상 아이콘이 있는 **색상 팔레트 열기 ↗** 버튼을 누릅니다.
- 창 위쪽은 **자유 색상**, 아래쪽은 **기본 팔레트 18색**입니다. 기본 색상도 클릭하면 메모에 미리보기되며 적용·취소 방식으로 확정합니다. 우클릭 메뉴의 기본 3색은 한 번 클릭해 바로 적용할 수 있습니다.
- 색상 면을 클릭·드래그하거나 색조·채도·밝기 슬라이더를 움직이면 메모에 즉시 미리보기됩니다. **HEX** 칸에는 `#3377BB`처럼 6자리 색상 코드를 입력할 수 있습니다.
- **적용** 또는 Enter로 확정합니다. **취소**·닫기·Esc는 원래 색으로 돌아갑니다. 미리보기는 자동 저장되지 않으므로 창을 닫거나 새로고침해도 미확정 색상으로 저장되지 않습니다.
- 적용한 색상은 최근 사용한 색상에 최대 8개 보관합니다. 메모 우클릭 메뉴의 최근 색상은 한 번 클릭해 바로 적용할 수 있습니다.
- 여러 메모를 선택한 상태에서는 기본 3색·사용자 팔레트·최근 색상 모두 선택한 메모 전체에 적용됩니다.
- 팔레트에서 색상을 여러 번 바꿔도 확정한 변경은 하나로 기록됩니다. **Ctrl + Z 한 번**으로 이전 색상들을 복원합니다.

## 배경 이미지

1. **P → 화면 꾸미기 → 배경 이미지 → 이미지 선택**에서 PNG·JPG·WebP 파일을 엽니다.
2. **화면 채우기 / 이미지 전체 보기 / 반복 배경** 중 표시 방식을 선택합니다.
3. **이미지 농도**로 배경을 연하게 조절할 수 있습니다.
4. **제거**로 이미지를 없애고 원래 배경지로 돌아갑니다. 이미지 변경·제거는 Ctrl + Z로 되돌릴 수 있습니다.

배경 이미지는 모든 페이지에 공통으로 적용되는 화면 배경입니다. 메모와 달리 보드를 이동하거나 확대해도 화면에 고정되어 있습니다. PNG·JPG·WebP, 최대 20MB 파일을 선택할 수 있으며 브라우저가 자동으로 크기와 용량을 줄여 보관합니다. 외부 이미지 주소를 입력하거나 서버에 업로드하는 방식은 사용하지 않습니다.

이미지는 자동 저장본과 JSON 백업 파일 안에 함께 들어갑니다. 다른 컴퓨터에서 JSON을 열면 같은 배경이 복원되므로 원본 이미지 파일을 별도로 옮길 필요가 없습니다. 이미지가 포함된 JSON을 다른 사람에게 전달하면 배경 이미지도 함께 전달됩니다.

## 저장과 복원

### 같은 컴퓨터에서 이어서 사용

- 변경 후 잠시 뒤 브라우저 저장소(localStorage)에 자동 저장됩니다. 같은 사이트·브라우저 프로필에서 새로고침하거나 재접속하면 복원합니다.
- 메모 내용·서식·배치·크기·분류·색상·그룹·블러, 페이지와 화면 위치, 테마·배경이 저장됩니다. 편집 완료 전의 입력도 복원 대상입니다.
- 페이지가 숨겨지거나 종료될 때도 저장을 시도합니다. 저장 공간 부족·저장 차단으로 실패하면 화면 아래에 경고와 **파일로 백업** 버튼이 나타납니다.
- 자동 저장되지 않았고 파일로도 백업하지 않은 변경이 있다면 페이지 이탈 시 브라우저의 기본 확인창을 요청합니다. 확인창의 표시 여부와 문구는 브라우저가 결정합니다.
- 가능한 경우 직전 자동 저장본을 보관하여 최신 저장본을 읽지 못할 때 복구합니다. 저장 공간이 부족하면 최신 저장을 우선합니다.
- 같은 브라우저에서 여러 탭을 열면 자동 저장 공간을 공유합니다. 다른 탭의 변경을 감지하면 자동 덮어쓰기를 멈추고, 다른 탭의 저장본을 불러올지 현재 보드를 저장할지 선택하게 합니다. 필요한 내용은 먼저 파일로 백업할 수 있습니다.

자동 저장은 서버 동기화가 아닙니다. 다른 브라우저·프로필·기기는 별도의 보드를 사용합니다. 브라우저 데이터 삭제, 비공개 모드 종료, 저장 공간 정리 등에 따라 자동 저장본이 사라질 수 있으므로 중요한 내용은 JSON 파일로도 백업하세요.

### 다른 컴퓨터로 옮기기

1. **Ctrl + S** 또는 **P → 파일로 저장**으로 `moa-board-날짜.json`을 다운로드합니다.
2. USB·메일 등으로 파일을 다른 컴퓨터에 옮깁니다.
3. 같은 사이트에서 **Ctrl + O** 또는 **P → 파일 불러오기**로 파일을 선택합니다.
4. 수정한 내용은 그 컴퓨터의 브라우저에 자동 저장됩니다. 원래 JSON 파일을 자동으로 덮어쓰지는 않으므로 최신 내용은 다시 파일로 백업해야 합니다.

파일 불러오기는 현재 보드를 파일 내용으로 교체하며 직후 Ctrl + Z로 되돌릴 수 있습니다. 잘못된 파일은 현재 보드를 교체하지 않습니다.

기존 **버전 1 JSON**도 불러올 수 있습니다. 기존 분류는 유지하고 새 메모에는 미리 정해진 분류를 넣지 않습니다. 새로 저장하는 **버전 2 JSON**에는 서식·크기·테마·배경도 포함됩니다. 이전 앱에서 버전 2 파일을 여는 것은 지원하지 않습니다.

파일 불러오기 제한: **10MB, 200개 페이지, 5,000개 메모**. 브라우저 자동 저장 용량은 브라우저 정책과 남은 공간에 따라 다릅니다.

### 개인정보

메모와 JSON 파일은 사용자 브라우저에서 처리됩니다. 공부 내용을 전송하는 외부 API나 서버 데이터베이스가 없으며 다른 사용자에게 자동 공개되지 않습니다. JSON을 다른 사람에게 전달하면 파일 내용도 공유됩니다. 블러는 암기를 돕는 가리기 효과이며 암호화 기능은 아닙니다.

## 단축키

| 키 | 기능 |
| --- | --- |
| M | 편집·암기 모드 전환 |
| P / ? | 전체 메뉴 / 사용법 안내 |
| N / F | 새 메모 / 현재 보기 전체 맞춤 |
| B | 암기 모드에서 선택 메모 블러 전환 |
| Enter / Ctrl + Enter | 선택 메모 편집 / 편집 완료 |
| Esc | 편집 취소 또는 메뉴 닫기 |
| Ctrl + B / Ctrl + U | 편집 중 선택 글자 굵게 / 밑줄 |
| Ctrl + C / Ctrl + V | 선택한 메모 복사 / 붙여넣기. 텍스트 편집 중에는 일반 텍스트 조작 |
| Ctrl + S / Ctrl + O | JSON 파일 백업 / 불러오기 |
| Ctrl + Z | 보드 변경 실행 취소. 텍스트 입력 중에는 브라우저의 편집 실행 취소 |
| Ctrl + A | 현재 보기 전체 선택. 텍스트 입력 중에는 텍스트 선택 |
| Ctrl + G / Ctrl + Shift + G | 같은 페이지의 선택 메모 그룹화 / 그룹 해제 |
| Ctrl + D / Delete | 선택 메모 복제 / 삭제 |

macOS에서는 Ctrl 대신 Command를 사용합니다. 텍스트 입력 중에는 P·M 같은 일반 문자 단축키가 실행되지 않습니다.

## 구성과 배포

| 파일 | 역할 |
| --- | --- |
| index.html | 화면·스타일·기능·아이콘을 포함한 앱 |
| README.md | 사용 안내 |
| .nojekyll | 정적 파일 배포 설정 |
| THIRD-PARTY-NOTICES.txt | 아이콘 라이선스 |

현재 공개 주소: **https://taetaeeee.github.io/moa-board/**

1. ZIP의 압축을 풀고 파일들을 저장소 `main` 브랜치의 최상위에 올립니다. ZIP 자체를 올리지 않습니다.
2. **Settings → Pages → Source: Deploy from a branch → main → /(root)**로 설정합니다.
3. 업데이트할 때는 `index.html`과 `README.md`를 교체합니다. 기존 JSON 백업 파일은 계속 불러올 수 있습니다.
4. 이전 화면이 남으면 배포 완료 여부를 확인한 뒤 Ctrl + Shift + R로 새 파일을 불러옵니다.

별도 빌드·API 키가 필요하지 않은 정적 사이트입니다. GitHub Actions로 같은 파일을 배포해도 됩니다. `index.html`을 직접 열 수도 있지만 `file://`의 자동 저장 동작은 브라우저마다 다를 수 있어 GitHub Pages 주소 사용을 권장합니다.
