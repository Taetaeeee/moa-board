# 모아보드 (Moa Board)

**메모를 자유롭게 배치하고, 내용을 가렸다가 확인하며 공부하는 웹 화이트보드**입니다.

**[▶ 모아보드 바로 사용하기](https://taetaeeee.github.io/moa-board/)**  
**[GitHub 저장소](https://github.com/Taetaeeee/moa-board)**

별도의 설치나 회원가입 없이 브라우저에서 바로 사용할 수 있습니다. 편집 모드로 학습 내용을 정리하고, 암기 모드로 내용을 가리면서 복습할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 자유로운 메모 배치 | 빈 보드에 메모를 만들고 드래그하여 원하는 위치에 배치 |
| 편집·암기 모드 | 학습 내용을 작성하거나 메모를 블러 처리해 암기 확인 |
| 페이지 관리 | 주제별 페이지를 만들고, 전체 모아보기로 모든 메모 확인 |
| 메모 꾸미기 | 색상, 분류, 가릴 범위 설정 및 메모 그룹화 |
| 화면 조작 | 보드 이동, 확대·축소, 메모 전체 맞춤 |
| JSON 저장·불러오기 | 작성한 보드를 파일로 내려받고 다른 PC에서 복원 |
| 시작 안내 | 첫 접속 시 사용법을 안내하는 팝업 표시 |

## 시작하기

1. **[모아보드 열기](https://taetaeeee.github.io/moa-board/)**에 접속합니다.
2. 시작 안내를 읽고 **시작하기**를 누릅니다. 처음에는 예시 메모가 없는 **빈 보드**가 표시됩니다.
3. **편집 모드**에서 빈 공간을 마우스 오른쪽 버튼으로 클릭해 메모를 추가합니다.
4. 메모를 **더블클릭**해 내용을 수정하고 **드래그**해 위치를 바꿉니다.
5. **암기 모드**로 전환한 후 메모를 오른쪽 버튼으로 클릭하면 내용을 가리거나 다시 확인할 수 있습니다.
6. 작업을 마칠 때 **Ctrl + S**로 보드 전체를 JSON 파일에 저장합니다.

> 시작 안내에서 **다음부터 보지 않기**를 선택하면 해당 브라우저에서 팝업이 생략됩니다. 나중에 **?** 키나 **P → 사용법 다시 보기**로 다시 확인할 수 있습니다.

## 사용 방법

| 동작 | 기능 |
| --- | --- |
| 편집 모드에서 빈 공간 우클릭 | 메모 생성 |
| 메모 더블클릭 | 제목 및 본문 수정 |
| 메모 드래그 | 메모 이동 |
| Shift + 메모 클릭 | 여러 메모 선택 |
| 편집 모드에서 메모 우클릭 | 메모 색상·분류·소속 페이지·가릴 범위·그룹 등 설정 |
| 같은 그룹의 메모를 선택한 후 드래그 | 선택한 그룹 메모를 함께 이동 |
| 빈 공간 드래그 / Space + 드래그 | 보드 화면 이동 |
| Ctrl + 마우스 휠 | 확대·축소 |
| 암기 모드에서 메모 우클릭 | 해당 메모 블러 켜기·끄기 |

**페이지 메뉴:** `P` 키를 눌러 새 페이지를 만들거나 페이지별 보기와 전체 모아보기를 전환할 수 있습니다. 파일 저장·불러오기 메뉴도 여기에서 열 수 있습니다.

**모바일:** 모바일 화면에서는 메모가 세로 목록으로 표시됩니다. 자유 배치와 우클릭 조작은 PC 브라우저를 권장합니다.

## 단축키

| 단축키 | 기능 |
| --- | --- |
| `M` | 편집 모드 ↔ 암기 모드 |
| `P` | 페이지·파일 메뉴 열기/닫기 |
| `?` | 사용법 다시 보기 |
| `N` | 새 메모 생성 |
| `F` | 현재 보기의 모든 메모 화면에 맞춤 |
| `B` | 암기 모드에서 선택한 메모 블러 전환 |
| `Enter` | 선택한 메모 수정 |
| `Ctrl + Enter` | 수정 완료 |
| `Esc` | 수정 취소 / 메뉴 닫기 |
| `Ctrl + S` | JSON 파일로 보드 전체 저장 |
| `Ctrl + O` | JSON 저장 파일 불러오기 |
| `Ctrl + Z` | 실행 취소 |
| `Ctrl + A` | 현재 보기의 메모 전체 선택 |
| `Ctrl + G` | 선택한 같은 페이지 메모 그룹화 |
| `Ctrl + Shift + G` | 그룹 해제 |
| `Ctrl + D` | 선택한 메모 복제 |
| `Delete` | 선택한 메모 삭제 |

macOS에서는 위의 `Ctrl` 단축키를 `Command`로 사용할 수 있습니다. 메모에 텍스트를 입력하는 동안에는 일반 문자 단축키가 동작하지 않습니다.

## 데이터 저장 및 다른 PC에서 사용하기

모아보드는 **계정·서버 데이터베이스 없이 동작하는 개인용 도구**입니다.

- **사용자별 독립:** 같은 URL에 접속하더라도 다른 사용자의 메모가 나타나지 않습니다. 브라우저에서 각자 별도의 보드를 사용합니다.
- **자동 저장 없음:** 메모 내용이 서버나 브라우저의 영구 저장소에 자동 저장되지 않습니다. 새로고침하거나 탭을 닫으면 작성한 내용이 사라질 수 있으므로 **파일로 저장**해야 합니다.
- **파일로 저장:** `Ctrl + S` 또는 `P → 파일로 저장`을 누르면 `moa-board-YYYY-MM-DD.json` 파일이 다운로드됩니다.
- **파일로 복원:** 같은 사이트에서 `Ctrl + O` 또는 `P → 파일 불러오기`로 저장했던 JSON 파일을 선택하면 모든 페이지와 메모를 복원할 수 있습니다.
- **다른 기기에서 이어서 사용:** 저장 파일을 다른 PC로 옮긴 다음 [모아보드](https://taetaeeee.github.io/moa-board/)에서 불러오면 됩니다. **기기 간 자동 동기화는 제공되지 않습니다.**
- **개인정보:** 메모 내용과 불러온 JSON 파일은 브라우저 내부에서 처리되며, 모아보드 서버에 업로드되지 않습니다. 다만 JSON 파일을 다른 사람에게 전달하면 파일 안의 메모 내용도 공유됩니다.

저장 파일에는 페이지·메모 내용·분류·색상·그룹·위치·화면 배치·블러 상태 등이 포함됩니다. **파일 불러오기는 현재 보드를 불러온 내용으로 교체**하며, 직후 `Ctrl + Z`로 되돌릴 수 있습니다. 잘못된 파일은 보드를 변경하지 않습니다.

**불러오기 제한:** JSON 파일 최대 10MB, 페이지 최대 200개, 메모 최대 5,000개.

## 프로젝트 구성

```text
moa-board/
├── index.html                # HTML·CSS·JavaScript가 포함된 웹 앱
├── README.md                 # 프로젝트 소개 및 사용법
└── THIRD-PARTY-NOTICES.txt   # 서드파티 아이콘 라이선스 고지
```

외부 API 키, 서버, 데이터베이스, 패키지 설치 또는 빌드 과정이 필요하지 않은 **정적 웹 페이지**입니다. `index.html`을 브라우저에서 직접 열어도 사용할 수 있습니다.

## GitHub Pages 배포 및 수정

현재 공개된 주소: **https://taetaeeee.github.io/moa-board/**

처음 배포하거나 저장소를 복제해 배포할 경우:

1. 저장소의 `main` 브랜치 최상위에 `index.html`, `README.md`, `THIRD-PARTY-NOTICES.txt`를 배치합니다.
2. GitHub 저장소에서 **Settings → Pages**로 이동합니다.
3. **Build and deployment**의 **Source**를 `Deploy from a branch`로 설정합니다.
4. **Branch**는 `main`, **Folder**는 `/(root)`로 선택하고 저장합니다.
5. 배포가 완료되면 GitHub Pages 주소로 접속합니다.

사이트 기능을 수정하려면 `index.html`을 변경한 뒤 `main` 브랜치에 커밋하면 됩니다. README만 수정할 때는 `README.md`만 교체하면 됩니다. 이 프로젝트는 별도의 GitHub Actions 워크플로 없이 브랜치에서 바로 배포할 수 있습니다.

참고: [GitHub Pages 게시 소스 설정 문서](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
