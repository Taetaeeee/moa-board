모아보드 · 시작 안내

이렇게 사용해요

빈 보드에 메모를 붙이고, 가리면서 외워보세요.

  • 메모 만들고 꾸미기빈 곳 우클릭으로 추가, 더블클릭해 편집.
    텍스트를 선택해 굵게·밑줄·형광펜을 적용해요.
    메모를 드래그해 이동하고 모서리로 크기를 바꿔요.
    Ctrl C 복사 · Ctrl V 붙여넣기.
    Ctrl + 휠로 확대·축소, 빈 곳 드래그로 여러 메모 선택.
    Space + 드래그 / 가운데 버튼으로 보드 이동.
  • 가리고, 떠올리고, 확인하기암기 모드에서 메모를 우클릭하면
    블러가 켜지고, 다시 누르면 내용이 보여요.
  • P 키는 보드의 전체 메뉴예요P → 페이지 추가·이동 / 전체 모아보기
    현재 페이지 정렬 / 파일 백업·불러오기 / 테마·배경 설정.
    F는 멀리 흩어진 메모까지 화면에 맞춰요.
  • 자동 저장하고, 파일로도 백업해요같은 브라우저에서는 새로고침해도 자동 복원돼요.
    다른 PC로 옮길 때는 Ctrl S로 JSON 백업,
    Ctrl O로 불러오기. 브라우저 데이터 삭제에 대비해 파일도 보관해 주세요.
