사용법과 단축키

필요한 항목을 펼쳐서 확인하세요.

메모 만들기 · 자료 넣기

메뉴 P → 자료로 메모 만들기에서 자료를 붙여넣고 미리보기를 만듭니다. 제목·본문을 수정하거나 제외·나누기·합치기를 한 뒤 추가하세요.

한 번에 10,000자 · 메모 50개까지 만들 수 있어요. 8,000자부터 안내하며, 한도를 넘으면 입력은 유지하고 생성을 막습니다. 원문을 문단·항목별로 나누고, 용어·소제목을 질문형으로 바꿀 수 있어요.

공통 태그를 고르거나 태그 없이 만들 수 있어요. 기존 메모를 선택하고 우클릭 → 내용으로 메모 나누기도 가능합니다.

직접 만들려면 빈 곳을 우클릭하세요. 메모를 더블클릭해 편집하고 Ctrl Enter 또는 완료로 마칩니다.

이동 · 여러 메모 선택 · 태그

메모를 드래그해 옮깁니다. 편집 모드에서 빈 곳을 드래그하면 여러 메모가 선택되고, Shift + 클릭·드래그로 선택을 추가할 수 있어요.

여러 메모 선택 → 우클릭 → 선택 메모 태그 편집에서 태그를 추가·제거·비울 수 있어요. 하나의 메모는 우클릭 메뉴에서 태그를 입력하거나 이미 사용한 태그를 선택합니다.

메모에 마우스를 올리거나 # 버튼을 누르면 태그가 보여요. 메뉴 P → 태그로 보기에서 분류별로 확인합니다. 여러 태그를 고르면 그중 하나라도 있는 메모를 표시해요.

글자 꾸미기 · 들여쓰기 · 메모 크기

글자를 선택한 뒤 B / U / 형광펜을 누르세요. 글자 크기는 10~72px로 조절하며, 커서만 두면 이후 입력하는 글자에 적용해요.

• 목록 버튼은 본문을 글머리 기호 목록으로 바꿉니다. Tab은 들여쓰기, Shift Tab은 내어쓰기이며 목록에서는 하위·상위 항목으로 바꿔요.

메모의 테두리·모서리를 드래그해 크기를 바꿉니다. 가로 테두리 더블클릭은 높이, 세로 테두리는 너비, 모서리는 둘 다 내용에 맞춰요.

메모 색상은 우클릭 → 색상 팔레트 열기에서 선택합니다. 여러 메모에도 함께 적용할 수 있어요.

화살표 · 그룹 · 복사

출발 메모 우클릭 → 이 메모에서 화살표 연결 → 같은 페이지의 도착 메모를 클릭하세요. 선을 선택하면 방향을 반전하거나 삭제할 수 있어요.

메모 선택 후 Ctrl C / Ctrl V로 복사·붙여넣기합니다. 여러 메모를 함께 복사하면 상대적인 배치와 내부 화살표도 유지해요.

Ctrl G로 같은 페이지의 선택 메모를 그룹화합니다. 그룹 전체를 옮기려면 우클릭 → 같은 그룹 선택 후 드래그하세요.

암기 모드

상단 암기 모드 또는 M으로 전환합니다. 메모를 우클릭해 가리고, 다시 우클릭해 확인하세요. 가릴 범위는 편집 모드의 메모 우클릭 메뉴에서 정합니다.

암기 모드에서는 메모 이동·크기 변경과 화살표 편집이 잠깁니다. 가림 효과는 학습용이며 암호화는 아닙니다.

페이지 · 화면 이동 · 꾸미기

메뉴 P에서 페이지를 추가·이동하고 전체 모아보기를 엽니다. 현재 페이지 정렬은 메모 위치를 실제로 바꾸고, 전체 맞춤 F는 화면 위치와 배율만 바꿔요.

Ctrl + 휠로 확대·축소합니다. 휠, 가운데 버튼 또는 Space + 드래그로 보드를 이동합니다. 암기 모드와 터치에서는 빈 곳을 드래그해 이동할 수 있어요.

메뉴 P → 화면 꾸미기에서 테마·배경지·배경색·이미지를 선택할 수 있어요.

자동 저장 · 파일 백업 · 다른 PC

같은 사이트와 브라우저 프로필에서는 새로고침·재접속 시 자동 저장본을 복원합니다. 저장 실패 시 보드 아래에 백업 안내가 나타나요.

다른 PC로 옮기거나 백업하려면 메뉴 P → 파일로 저장 또는 Ctrl S로 JSON을 저장하세요. 옮긴 PC에서 파일 불러오기 또는 Ctrl O로 엽니다.

생성 전 입력 자료와 미리보기는 현재 탭에 임시 보관됩니다. 브라우저 데이터 삭제·비공개 모드 종료 등에 대비해 중요한 원문과 JSON 파일을 별도로 보관하세요.

메모는 서버로 동기화되지 않습니다. 브라우저·프로필·기기가 다르면 별도의 보드를 사용해요.
